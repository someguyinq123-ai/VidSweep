// features

Two layers of detection. One human decision.

VidSweep doesn't just compare filenames or hashes. It decodes four sampled frames from every video, hashes them perceptually, and cross-checks duration overlap — so a sharp 720p wins over a blurry “1080p” automatically.

01 / perceptual matching

Catches re-encodes the easy dedup tools miss.

The same video can be re-encoded at any resolution, bitrate, or container — mp4 → mkv → avi. SHA-256 won't find them; VidSweep's 4-frame pHash will.

  • Two videos match when 3 of 4 frames agree and duration overlaps ≥ 10%.
  • Hardware-accelerated via NumPy popcount, with vectorized pure-Python fallback.
  • Tunable sensitivity with a plain-language guide.
02 / review at speed

You decide. Quickly.

Every duplicate group renders as a thumbnail grid with resolution, size, codec, and duration. The best copy is pre-marked Keep; one click marks the rest across every group, another executes.

  • LRU-capped thumbnail cache — long review sessions don't grow memory.
  • Background-threaded matching — the window stays interactive during multi-minute scans.
  • Confirmation dialog lists every file before anything moves.
03 / safe removal

Recycle Bin, quarantine, or secure delete.

Pick the safety net you want. Defaults to the OS Recycle Bin so you can recover. Move-to-folder never overwrites — collisions get numbered suffixes. Optional secure delete overwrites bytes before removal.

  • Removal paths: Recycle Bin · quarantine folder · permanent · secure-overwrite.
  • Name-based category organizer with full move preview.
  • Every action is logged; nothing happens without a confirm dialog.
// how it works

Add folders. Scan. Review. Done.

The first scan decodes four frames per video (a 30k library takes a few hours). Every rescan only touches new or changed files, so it's nearly instant.

Add folders

Drag in any number of roots. VidSweep walks them, picks up video files, and ignores the rest.

Scan

Decodes 4 sampled frames per file, hashes them, and stores everything in a local SQLite cache. Pause and resume any time.

Review

Duplicate groups render as thumbnail grids. Best copy is pre-marked Keep. Click to override.

Execute

One click moves marked files to Recycle Bin (or your chosen destination). The confirmation dialog lists every file.

// install

Two commands. No installer.

Requires Python 3.11+ and ffmpeg/ffprobe (the GUI has a “Locate ffmpeg…” button if it can't find one).

Windows

Double-click VidSweep.bat. It auto-locates a suitable Python and offers one-time dependency setup.

Linux / macOS

Install once, then launch with python3 gui.py. NumPy is optional but recommended — it makes matching several times faster.

Python 3.11+ ffmpeg / ffprobe Pillow · imagehash · send2trash NumPy (recommended)
install · bash~ 30 seconds
# 1. dependencies
pip install pillow imagehash send2trash numpy

# 2. grab the code
git clone https://github.com/someguyinq123-ai/VidSweep.git
cd VidSweep

# 3. launch
python3 gui.py
